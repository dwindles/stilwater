    Playing co-op

    1. Both of you start the game from Stilwater. The launcher signs out while the game runs, because the game uses the same account.
    2. Host: load your save, open Co-op and choose Online.
    3. Friend: Co-op → Online, then join from the list or accept the invite.
    4. Check that your mods codes match first. Different mods can desync or crash the session.
    Mods code … Should match your co-op partner's. Changes apply the next time the game starts.
